# Six&7 — Shopify Footwear Portfolio

## Overview

Six&7 is an unpublished Shopify footwear portfolio built on Dawn and Online Store 2.0. The project combines custom Liquid development, a premium responsive visual system and verified native commerce interactions, while preserving the live store and merchant configuration.

## Challenge

Sixteen approved, image-backed products remained Draft with zero inventory and provisional Color/Size labels. Ordinary Draft product URLs were inaccessible. A useful portfolio demonstration needed to show the actual designs without publishing products, inventing stock or implying that unverified options were sale-ready. Theme work also needed to preserve newer remote editor settings and Judge.me integration.

## Solution

A reusable Liquid concept section renders a verified snapshot of the approved images, titles, descriptions and USD prices. Native disclosure cards let visitors explore each concept in place, with explicit “Portfolio Demo — Not Available for Purchase” messaging. The existing catalog was retained and made easier to locate in the editor; it was not duplicated as a fabricated product or page.

Editable demo settings control visibility, homepage metadata and the header text wordmark. Custom CSS maintains Six&7's black, white and silver identity with restrained red accents. Existing Active products retain Dawn's normal variants, galleries and cart behavior. Scoped Draft-only uploads were checked against fresh remote files and independently verified after download.

## Features

- Sixteen concept previews across four audience/demo groups, with six homepage highlights.
- Responsive hero, header/mobile navigation, collection cards, product galleries, About, Contact and footer.
- Keyboard-operable concept details, visible focus states, product-specific accessible control names and reduced-motion support.
- Consistent premium About links, SEO/social metadata fallbacks and honest portfolio policy information.
- Native search, filtering, sorting and Active-product cart/checkout-entry demonstration.

## Verified results

The final QA run recorded **64 passed checks, no unresolved failures and four documented blockers**. Tested layouts fit at 390/768/1440 CSS pixels. Theme Check returned **zero errors and nine existing warnings**. All 16 product records retained their Draft status, 192 variants, zero inventory, prices, media and collection memberships. No product or theme was published; Live Horizon was preserved.

This is an engineering and design portfolio demonstration, not a launched sales channel. Native Draft product-page preview remains unresolved; shipping/refund/terms policies are missing, and payment/shipping/tax/fulfillment readiness is unverified. No conversion uplift, revenue result or exhaustive accessibility certification is claimed.
